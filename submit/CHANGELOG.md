# Changelog

## 1.0.0 - 2026-07-31

- Added a complete project importable by WeChat DevTools.
- Added the reusable `golf-poster` custom component.
- Ported all six poster templates and palette presets.
- Ported fixed-preview, seven-step editing, and summary jump-back workflow.
- Added native Canvas 2D rendering and 1000 x 1265 PNG export.
- Added photo movement, pinch scaling, background blur, and layout reset.
- Added strokes/to-par input, automatic gross total, PGA TOUR and DP World Tour markers.
- Added score color locking for colored scorecard boards.
- Added independent total, identity, and scorecard controls.
- Added up to five movable and scalable sticker images.
- Added full-screen direct editing with element hit testing.
- Added an optional HTTPS person-segmentation adapter with full-photo fallback.
- Added Chinese and English interface switching.
